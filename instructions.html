Scroll Library(📜 button[on the top side of the rightside of the screen])

click the scroll button it will open a new screen where you will see 12 scrolls in total clicking one any of them open the scroll you can write the title and write whatever you want to keep saved once you are done you can click save to save it and if you need to delete it just click the delete button below it. Then there is a search button which will let you search scrolls you just need to type the title in the search bar and it will filter it for you there are two buttons next to it 'next' and 'back' they are used to navigate between scrolls(if you have used all the 12 scrolls on your screen it will allow you to press the next button which will produce the new set of 12 empty scrolls which you can then use) so the 'next' and 'back' buttons are given to navigate between the set of 12 scrolls each page. Also you will see the no. of scrolls saved. On the left side of the screen you will see a cross you can use it to get out of the scroll section. Also which ever scroll you use the code will auto sort it number wide which means you directly used the 10th scroll, then once you save it it drectly becomes the 1st scroll(or whatever scroll is after a used scroll)
